Support

Something broken, stuck or unclear? Use REPORT A BUG in the game's main menu or pause menu: it attaches what we need to find the problem.

Or write to Forgottenpixelsthe8thseal@gmail.com. Please say which platform you play on (PC or Android), the game version (shown under LEGAL in the game) and what happened.

To ask us to delete a bug report you sent, write to the same address with the report ID shown on screen after sending.
